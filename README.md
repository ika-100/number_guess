# 数当てゲーム（Number Guess Game）

1〜100のランダムな数字を当てる、シンプルなPythonゲームです。

## 概要
プログラムがランダムに決めた数字を、ユーザーが入力して当てます。
入力した数字が正解より大きいか小さいかのヒントが表示されます。

## 使い方
1. プログラムを実行します
2. 表示に従って数字を入力します
3. 正解すると、何回で当たったかが表示されます

## 実行例
数字を入力してください！:50  
もっと小さい数字です！  
数字を入力してください！:25  
もっと大きい数字です！  

## 学習ポイント
- random モジュールの使い方
- while 文による繰り返し処理
- 入力値のチェック（isdigit）
